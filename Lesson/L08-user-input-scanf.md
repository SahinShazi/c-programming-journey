# পাঠ ০৮: ইউজার ইনপুট নেওয়া — `scanf()`

## সংক্ষিপ্ত বিবরণ

এতদিন আমরা প্রোগ্রামের ভেতরেই ভেরিয়েবলের মান বসিয়ে দিয়েছি (যেমন `int a = 10;`)। কিন্তু বাস্তব প্রোগ্রামে প্রায়ই দরকার হয় **ইউজারের কাছ থেকে ডেটা নেওয়া** — যেমন তাদের বয়স, নাম, বা কোনো সংখ্যা। এই কাজেই ব্যবহার হয় `scanf()` ফাংশন।

## প্রোগ্রামটি

```c
#include <stdio.h>

int main(){
    int a, b;
    float c, d;
    char ch[50];
    
    printf("Enter value a 👇\n");
    scanf("%d",&a);
    printf("Enter value b 👇\n");
    scanf("%d", &b);
    printf("Enter value c & d 👇\n");
    scanf("%f %f", &c, &d);
    printf("What's your wife name?\n");
    scanf("%c[^\n]", ch);
    
    printf("%d + %d = %d\n", a, b, a + b);
    printf("b = %d\n", b);
    printf("a = %d\n", a);
    
    printf("c = %f\n", c);
    printf("d = %f\n", d);
    printf("%f + %f = %f\n", c, d, c + d); 
    
    printf("WOW! Your wife name is Nice!!");

    return 0;
}
```

## `scanf()` কী করে?

> **`scanf()` হলো একটি ফাংশন, যেটা কীবোর্ড থেকে ইউজারের টাইপ করা ডেটা পড়ে, সেটা নির্দিষ্ট ফরম্যাটে রূপান্তর করে, এবং একটি ভেরিয়েবলে সংরক্ষণ করে।**

এটা অনেকটা `printf()`-এর উল্টো কাজ:
- `printf()` → ডেটা **স্ক্রিনে পাঠায়** (আউটপুট)
- `scanf()` → ডেটা **কীবোর্ড থেকে নেয়** (ইনপুট)

## একসাথে অনেকগুলো ভেরিয়েবল ডিক্লেয়ার করা

```c
int a, b;
float c, d;
char ch[50];
```

খেয়াল করো, তুমি একই টাইপের একাধিক ভেরিয়েবল একসাথে, কমা দিয়ে আলাদা করে ডিক্লেয়ার করতে পারো — এটা এরকম লেখার সংক্ষিপ্ত রূপ:
```c
int a;
int b;
```

`char ch[50];` লাইনটি একটু ভিন্ন — এটা একটি **ক্যারেক্টার অ্যারে (array)** তৈরি করছে, ৫০টি ক্যারেক্টার ধারণ করার জায়গাসহ। এটা মূলত একটি **স্ট্রিং** (টেক্সট) রাখার উপায় — অ্যারে সম্পর্কে বিস্তারিত পরের কোনো পাঠে শেখানো হবে, কিন্তু এখন এটুকু জেনে রাখো: একাধিক ক্যারেক্টার (যেমন একটা নাম) রাখতে হলে একটাই `char` ভেরিয়েবল যথেষ্ট না, তাই `char`-এর একটা অ্যারে লাগে।

## `&` চিহ্নটা কেন লাগে?

```c
scanf("%d", &a);
```

লক্ষ্য করো `a`-এর আগে একটি `&` চিহ্ন আছে। এটাকে বলে **অ্যাড্রেস-অফ অপারেটর (address-of operator)**।

- সাধারণ ব্যবহারে (যেমন `printf`-এ) আমরা ভেরিয়েবলের **মান** দিই।
- কিন্তু `scanf`-কে জানতে হয় ভেরিয়েবলটি মেমোরির **কোন জায়গায়** আছে, যাতে সে সরাসরি সেই জায়গায় গিয়ে নতুন ডেটা লিখে দিতে পারে।
- `&a` মানে হলো "`a`-এর মেমোরি অ্যাড্রেস" — অর্থাৎ `a` ভেরিয়েবলটি ঠিক কোথায় সংরক্ষিত আছে।

এটা পাঠ ০৫-এ শেখা মেমোরি অ্যাড্রেসের ধারণার সাথে সরাসরি সম্পর্কিত। এই বিষয়ে আরও গভীরে যাবে **পয়েন্টার (pointer)** নামের একটি অধ্যায়ে, পরবর্তী কোনো পাঠে।

## একসাথে একাধিক মান নেওয়া

```c
scanf("%f %f", &c, &d);
```

একটি `scanf` কলেই একাধিক মান নেওয়া যায় — শুধু ফরম্যাট স্ট্রিং-এ একাধিক স্পেসিফায়ার দাও এবং তার সাথে মিলিয়ে একাধিক ভেরিয়েবলের অ্যাড্রেস দাও। ইউজার সাধারণত মানগুলো স্পেস দিয়ে আলাদা করে টাইপ করবে, যেমন: `12.5 8.3` লিখে এন্টার চাপবে।

## ⚠️ শেষ `scanf`-এ একটি বাগ (bug)

```c
scanf("%c[^\n]", ch);
```

এই লাইনটিতে দুটো সমস্যা আছে:

**সমস্যা ১: এটা স্ট্রিং পড়ার সঠিক সিনট্যাক্স নয়**

মনে হচ্ছে এখানে ইউজারের পুরো নাম (স্পেসসহ, যেমন "Rina Akter") পড়ার চেষ্টা করা হয়েছে। কিন্তু `%c[^\n]` কোনো বৈধ ফরম্যাট স্পেসিফায়ার নয় — এটা `%c` (একটি মাত্র ক্যারেক্টার পড়ার জন্য) এবং `[^\n]` (যেটা একটা ভিন্ন ফিচার, "স্ক্যানসেট") এর একটা ভুল মিশ্রণ। এর ফলে প্রোগ্রাম ঠিকমতো পুরো নাম পড়তে পারবে না।

**সঠিক উপায়গুলো:**

স্পেসসহ পুরো লাইন পড়তে চাইলে:
```c
scanf(" %[^\n]", ch);
```
এখানে `%[^\n]` মানে হলো "নিউলাইন (`\n`) না আসা পর্যন্ত যা কিছু টাইপ করা হয়, সব পড়ো" — এটাকে বলে স্ক্যানসেট। শুরুতে একটা স্পেস (` %[^\n]`) দেওয়া হয়, যাতে আগের ইনপুট থেকে থেকে যাওয়া কোনো অতিরিক্ত নিউলাইন বা স্পেস আগে থেকেই বাদ পড়ে যায়।

শুধু একটা শব্দ (স্পেস ছাড়া) পড়তে চাইলে:
```c
scanf("%s", ch);
```

**সমস্যা ২: `char` অ্যারের সাইজ নিয়ে সতর্কতা**

`ch` অ্যারেটি মাত্র ৫০ ক্যারেক্টার ধরে রাখতে পারে। ইউজার যদি ৫০ ক্যারেক্টারের বেশি টাইপ করে, প্রোগ্রামে মেমোরি সমস্যা (buffer overflow) হতে পারে। এই বিষয়টা নিয়ে অ্যারে ও স্ট্রিং-এর পাঠে আরও বিস্তারিত আলোচনা হবে।

## মূল শিক্ষণীয় বিষয়

- `scanf()` কীবোর্ড থেকে ইউজারের ইনপুট নিয়ে একটি ভেরিয়েবলে জমা রাখে।
- `scanf`-এ প্রতিটি ভেরিয়েবলের আগে `&` (অ্যাড্রেস-অফ অপারেটর) বসাতে হয়, যাতে `scanf` জানে ডেটাটা মেমোরির কোথায় লিখতে হবে।
- একটি `scanf` কলে একাধিক ফরম্যাট স্পেসিফায়ার দিয়ে একাধিক মান একসাথে নেওয়া যায়।
- স্পেসসহ পুরো লাইন (যেমন একটা নাম) পড়তে `%[^\n]` স্ক্যানসেট ব্যবহার করতে হয়, `%c[^\n]` নয় — এটা একটা সাধারণ ভুল।
- `char` অ্যারের একটা নির্দিষ্ট সাইজ থাকে, এবং সেই সীমার বেশি ডেটা রাখা উচিত নয়।

## সাধারণ ভুলগুলো

- `scanf`-এ `&` বসাতে ভুলে যাওয়া (যেমন `scanf("%d", a);` — এটা ভুল, হওয়া উচিত `scanf("%d", &a);`)।
- স্ট্রিং পড়ার সময় `char` অ্যারের নামের আগে `&` বসিয়ে দেওয়া — অ্যারের ক্ষেত্রে এটা দরকার নেই (অ্যারের নাম নিজেই তার মেমোরি অ্যাড্রেস নির্দেশ করে)।
- ভুল বা অস্তিত্বহীন ফরম্যাট স্পেসিফায়ার ব্যবহার করা, যেমন এই পাঠের `%c[^\n]`।
- একাধিক `scanf` কলের মাঝে ইনপুট বাফারে থেকে যাওয়া অতিরিক্ত নিউলাইন/স্পেসের সমস্যা খেয়াল না করা।

## অনুশীলনী

1. প্রোগ্রামের শেষ `scanf` লাইনটি ঠিক করো, যাতে এটা ইউজারের পুরো নাম (স্পেসসহ) সঠিকভাবে পড়তে পারে। ঠিক করার পর `printf` দিয়ে সেই নামটা প্রিন্ট করো।
2. একটি নতুন `int` ভেরিয়েবল `age` ডিক্লেয়ার করো, `scanf` দিয়ে ইউজারের বয়স নাও, এবং সেটা প্রিন্ট করো।
3. ভাবো তো — যদি তুমি `scanf("%d", &a);`-এ ভুলে `&` বাদ দাও, তাহলে কী ধরনের সমস্যা হতে পারে? (এখনই উত্তর জানার দরকার নেই — এটা নিয়ে আমরা পয়েন্টারের পাঠে ফিরে আসব।)
