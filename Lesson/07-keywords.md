# পাঠ ০৭: কনস্ট্যান্ট (Constant) ও রিজার্ভড কীওয়ার্ড (Reserved Keywords)

## সংক্ষিপ্ত বিবরণ

পাঠ ০৫-এ আমরা শিখেছি ভেরিয়েবল হলো এমন একটি ডেটা-কৌটা, যার মান পরিবর্তন করা যায়। কিন্তু কখনো কখনো তোমার এমন একটি মান দরকার হয়, যেটা প্রোগ্রাম চলাকালীন **কখনো পরিবর্তন হওয়া উচিত নয়** — একেই বলে **কনস্ট্যান্ট**। এই পাঠে আমরা শিখব কনস্ট্যান্ট কীভাবে তৈরি করতে হয়, এবং সি ভাষার কিছু **রিজার্ভড কীওয়ার্ড** সম্পর্কেও জানব, যেগুলো ভেরিয়েবলের নাম হিসেবে ব্যবহার করা যায় না।

## কনস্ট্যান্ট (Constant) কী?

> **কনস্ট্যান্ট হলো এমন একটি ভেরিয়েবল, যার মান একবার সেট হওয়ার পর প্রোগ্রামের মধ্যে আর পরিবর্তন করা যায় না।**

ভেরিয়েবলের সাথে পার্থক্য মনে রাখো:
| | ভেরিয়েবল | কনস্ট্যান্ট |
|---|---|---|
| মান | পরিবর্তনযোগ্য (changeable) | অপরিবর্তনীয় (unchangeable) |
| ব্যবহার | ডেটা যা প্রোগ্রাম চলাকালীন বদলাতে পারে | ডেটা যা কখনো বদলানো উচিত নয় (যেমন π-এর মান, বা কোনো ফিক্সড রেট) |

### সি-তে কনস্ট্যান্ট তৈরি করার উপায়

**পদ্ধতি ১: `const` কীওয়ার্ড ব্যবহার করে**

ডেটা টাইপের আগে `const` শব্দটি বসিয়ে দিলেই একটি ভেরিয়েবল কনস্ট্যান্টে পরিণত হয়:

```c
const float PI = 3.14;
```

এখন যদি তুমি এই প্রোগ্রামের কোথাও `PI`-এর মান বদলানোর চেষ্টা করো (যেমন `PI = 3.5;`), কম্পাইলার একটি **এরর** দেখাবে এবং প্রোগ্রাম কম্পাইলই হবে না। এটাই সুরক্ষার মূল সুবিধা — ভুলবশত কোথাও গুরুত্বপূর্ণ মান বদলে ফেলার ঝুঁকি থাকে না।

**পদ্ধতি ২: `#define` ব্যবহার করে**

আরেকটি উপায় হলো প্রিপ্রসেসর ডাইরেক্টিভ `#define` ব্যবহার করা:

```c
#define PI 3.14
```

খেয়াল করো:
- এখানে কোনো ডেটা টাইপ লেখা হয় না।
- লাইনের শেষে সেমিকোলন (`;`) থাকে না।
- এটি একটি **প্রিপ্রসেসর ডাইরেক্টিভ** — কম্পাইলার আসল কম্পাইলেশন শুরু করার আগেই, কোডের প্রতিটি জায়গায় `PI` লেখা দেখলে সরাসরি `3.14` বসিয়ে দেয়।

### দুটো উদাহরণ একসাথে

```c
#include <stdio.h>
#define PI 3.14159

int main() {
    const int MAX_STUDENTS = 60;
    
    printf("Value of PI: %f\n", PI);
    printf("Max students allowed: %d\n", MAX_STUDENTS);
    
    return 0;
}
```

এখানে:
- `PI` তৈরি হয়েছে `#define` দিয়ে — ব্যবহারের সময় কোনো টাইপ বা সেমিকোলনের দরকার নেই।
- `MAX_STUDENTS` তৈরি হয়েছে `const int` দিয়ে — এটি একটি সাধারণ ভেরিয়েবল ডিক্লেয়ারেশনের মতোই দেখতে, শুধু সামনে `const` বসানো।

**কনভেনশন (রীতি):** কনস্ট্যান্টের নাম সাধারণত সব **বড় হাতের অক্ষরে (UPPERCASE)** লেখা হয় (যেমন `PI`, `MAX_STUDENTS`), যাতে কোড পড়ার সময় সহজেই বোঝা যায় এটি একটি কনস্ট্যান্ট।

## রিজার্ভড কীওয়ার্ড (Reserved Keywords) কী?

> **রিজার্ভড কীওয়ার্ড হলো এমন শব্দ, যেগুলোর একটি নির্দিষ্ট অর্থ ও কাজ সি ভাষায় আগে থেকেই ঠিক করা আছে — তুমি এগুলোকে ভেরিয়েবল, ফাংশন, বা অন্য কোনো কিছুর নাম হিসেবে ব্যবহার করতে পারবে না।**

এই পাঠ পর্যন্ত তুমি ইতিমধ্যে বেশ কয়েকটি রিজার্ভড কীওয়ার্ডের সাথে পরিচিত হয়ে গেছ:
- `int`, `float`, `char`, `double` — ডেটা টাইপ ঘোষণা করতে ব্যবহৃত হয়
- `const` — কনস্ট্যান্ট তৈরি করতে ব্যবহৃত হয়
- `return` — একটি ফাংশন থেকে মান ফেরত পাঠাতে ব্যবহৃত হয়

সি ভাষায় মোট প্রায় ৩২টি রিজার্ভড কীওয়ার্ড আছে। কিছু গুরুত্বপূর্ণ উদাহরণ:

| কীওয়ার্ড | কাজ |
|---|---|
| `int`, `float`, `double`, `char` | ডেটা টাইপ |
| `const` | কনস্ট্যান্ট তৈরি করা |
| `if`, `else` | কন্ডিশন (শর্ত) যাচাই করা |
| `for`, `while`, `do` | লুপ (loop) তৈরি করা |
| `return` | ফাংশন থেকে মান ফেরত দেওয়া |
| `void` | "কোনো মান নেই" বোঝানো |

### কেন এগুলো "রিজার্ভড"?

কম্পাইলার এই শব্দগুলোকে বিশেষ অর্থ দিয়ে আগে থেকেই চিনে রাখে। তাই যদি তুমি লিখো:

```c
int return = 10;   // ❌ এরর! "return" একটি রিজার্ভড কীওয়ার্ড
```

কম্পাইলার বুঝতে পারবে না তুমি কি `return` কীওয়ার্ডটি ব্যবহার করছ, নাকি একটি ভেরিয়েবলের নাম বানাতে চাইছ — ফলে এটি একটি **কম্পাইল-টাইম এরর** দেবে।

## মূল শিক্ষণীয় বিষয়

- **কনস্ট্যান্ট** এমন একটি মান, যা একবার সেট হওয়ার পর প্রোগ্রামে আর পরিবর্তন করা যায় না।
- কনস্ট্যান্ট তৈরির দুটি সাধারণ উপায়: `const` কীওয়ার্ড (ডেটা টাইপসহ, সেমিকোলনসহ) এবং `#define` (কোনো টাইপ বা সেমিকোলন ছাড়াই, প্রিপ্রসেসর দিয়ে হ্যান্ডেল হয়)।
- কনভেনশন অনুযায়ী কনস্ট্যান্টের নাম সাধারণত UPPERCASE-এ লেখা হয়।
- **রিজার্ভড কীওয়ার্ড** হলো এমন শব্দ, যা সি ভাষায় আগে থেকেই নির্দিষ্ট অর্থ বহন করে (`int`, `const`, `if`, `for`, `return` ইত্যাদি) — এগুলো ভেরিয়েবল বা ফাংশনের নাম হিসেবে ব্যবহার করা যায় না।
- রিজার্ভড কীওয়ার্ড দিয়ে নাম রাখার চেষ্টা করলে কম্পাইলার এরর দেবে।

## সাধারণ ভুলগুলো

- `const` দিয়ে ডিক্লেয়ার করা ভেরিয়েবলের মান পরে পরিবর্তন করার চেষ্টা করা — এতে কম্পাইল এরর হবে।
- `#define`-এর শেষে ভুলবশত সেমিকোলন বসিয়ে দেওয়া (এটা `#define`-এর ক্ষেত্রে সঠিক নয়, `const`-এর ক্ষেত্রে সঠিক)।
- না জেনেই কোনো রিজার্ভড কীওয়ার্ড (যেমন `int`, `for`, `char`) ভেরিয়েবলের নাম হিসেবে ব্যবহার করার চেষ্টা করা।

## অনুশীলনী

1. `const` কীওয়ার্ড ব্যবহার করে একটি কনস্ট্যান্ট তৈরি করো, নাম `GRAVITY`, মান `9.8` (একটি `float`)।
2. `#define` ব্যবহার করে আরেকটি কনস্ট্যান্ট তৈরি করো, নাম `SCHOOL_NAME`, যার মান তোমার পছন্দের যেকোনো টেক্সট।
3. ইচ্ছাকৃতভাবে তোমার `GRAVITY` কনস্ট্যান্টের মান পরিবর্তন করার চেষ্টা করো এবং দেখো কম্পাইলার কী এরর দেয়।
