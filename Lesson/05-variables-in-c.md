# পাঠ ০৫: সি ভাষায় ভেরিয়েবল (Variables) বোঝা

## সংক্ষিপ্ত বিবরণ

এতক্ষণ তুমি শুধু প্লেইন টেক্সট প্রিন্ট করেছ, এমনকি `printf()`-এর ভেতরেই সরাসরি হিসাব করেছ (যেমন `6+7`)। কিন্তু বাস্তব প্রোগ্রামগুলো সাধারণত কোডে সরাসরি বসানো ফিক্সড সংখ্যা নিয়ে কাজ করে না — তারা কাজ করে এমন **ডেটা নিয়ে যা পরিবর্তনশীল**। এটাই হলো **ভেরিয়েবল**-এর কাজ।

এই পাঠে আমরা যা শিখব:
- ভেরিয়েবল আসলে কী
- মেমোরিতে ডেটা কীভাবে সংরক্ষিত হয়
- সি-তে ভেরিয়েবল কীভাবে ডিক্লেয়ার (declare) ও ব্যবহার করতে হয়
- সরাসরি সংখ্যা বসানোর চেয়ে ভেরিয়েবল কেন ভালো
- দুটি ভেরিয়েবল দিয়ে গাণিতিক হিসাবের একটি সম্পূর্ণ কোড উদাহরণ

## ভেরিয়েবল আসলে কী?

> **ভেরিয়েবল হলো একটি স্টোরেজ এরিয়ার (storage area) নাম, যা আমাদের প্রোগ্রাম পরিবর্তন করতে পারে।**

একটি ভেরিয়েবলকে ভাবতে পারো একটি **লেবেল-লাগানো কৌটা (container)** হিসেবে, যেটার ভেতরে কোনো একটি ডেটা রাখা থাকে — একটি সংখ্যা, কিছু টেক্সট ইত্যাদি। কৌটাটি নিজে পরোয়া করে না ভেতরে কী আছে; তুমি (প্রোগ্রামার) ঠিক করো এতে কোন ধরনের ডেটা থাকবে এবং কী মান দেওয়া হবে।

"নাম দেওয়া একটি ডেটা-কৌটা" — এই একই মূল ধারণা তুমি যেকোনো প্রোগ্রামিং ভাষায় (Python, JavaScript, Java, PHP ইত্যাদি) পাবে। শুধু ভাষা ভেদে ডিক্লেয়ার করার সিনট্যাক্স আলাদা হয়।

## ভেরিয়েবল আসলে কোথায় থাকে? (মেমোরি ও RAM)

কম্পিউটার ভেতরে ভেতরে শুধু **বাইনারি** বোঝে — ১ আর ০। তোমার প্রোগ্রামে ব্যবহৃত প্রতিটি ডেটা (সংখ্যা, টেক্সট, যা-ই হোক না কেন) শেষ পর্যন্ত মেমোরিতে বাইনারি আকারে সংরক্ষিত থাকে।

- কম্পিউটারে থাকে **RAM (Random Access Memory)** — এটি **টেম্পোরারি (অস্থায়ী) মেমোরি**, যা প্রোগ্রাম চলাকালীন ডেটা ধরে রাখতে ব্যবহৃত হয়।
- এটি **পার্মানেন্ট মেমোরি** (যেমন তোমার হার্ড ড্রাইভ/SSD) থেকে ভিন্ন, যেটা কম্পিউটার বন্ধ হওয়ার পরেও ডেটা ধরে রাখে।
- তুমি যখন একটি ভেরিয়েবল ডিক্লেয়ার করো, কম্পাইলার তখন RAM-এ তার জন্য একটু জায়গা রিজার্ভ করে, এবং সেই জায়গাটির একটি **মেমোরি অ্যাড্রেস** দেয়।
- তোমাকে নিজে সেই অ্যাড্রেসের হিসাব রাখতে হয় না — তুমি শুধু তোমার বেছে নেওয়া **ভেরিয়েবলের নাম** দিয়ে ডেটার কথা বলবে, বাকিটা কম্পাইলার পেছন থেকে সামলে নেয়।

এই কারণেই RAM-কে "random access" বলা হয় — কম্পাইলার যেকোনো মেমোরি অ্যাড্রেসে সরাসরি যেতে পারে, ধারাবাহিকভাবে সবকিছু খুঁজে বের করার দরকার হয় না।

## সি-তে একটি ভেরিয়েবল ডিক্লেয়ার করা

সি হলো একটি **স্ট্যাটিক্যালি টাইপড (statically typed)** ভাষা। এর মানে হলো:
- ভেরিয়েবল ডিক্লেয়ার করার সময় তোমাকে অবশ্যই তার **ডেটা টাইপ** বলে দিতে হবে।
- সেই ভেরিয়েবল তার পুরো জীবনকাল জুড়ে শুধু সেই টাইপের ডেটাই ধরে রাখতে পারবে (Python বা JavaScript-এর মতো কিছু ভাষার বিপরীতে, যেখানে একটি ভেরিয়েবলের টাইপ পরিবর্তন হতে পারে)।

### সিনট্যাক্স
```c
data_type variable_name = value;
```

### উদাহরণ
```c
int age = 20;
```

এটি ভেঙে দেখা যাক:
- `int` — **ডেটা টাইপ** (এই ক্ষেত্রে একটি পূর্ণসংখ্যা/ইন্টিজার)
- `age` — **ভেরিয়েবলের নাম** (এটা তুমি বেছে নাও; এটা অর্থবহ হওয়া উচিত)
- `=` — **অ্যাসাইনমেন্ট অপারেটর** (ডানপাশের মান বামপাশের ভেরিয়েবলে বসায় — এটা গণিতের "সমান" চিহ্নের মতো *নয়*)
- `20` — যে মানটি সংরক্ষণ করা হচ্ছে
- `;` — সি-তে যেমন সবসময়, স্টেটমেন্টের শেষ চিহ্ন

শুরুতে যেসব বেসিক ডেটা টাইপের সাথে পরিচিত হবে:
| টাইপ | যা সংরক্ষণ করে |
|---|---|
| `int` | পূর্ণসংখ্যা (যেমন `10`, `-5`, `2024`) |
| `float` / `double` | দশমিক সংখ্যা (যেমন `3.14`) |
| `char` | একটি একক ক্যারেক্টার (যেমন `'A'`) |

## সরাসরি সংখ্যা বসানোর বদলে ভেরিয়েবল কেন ব্যবহার করব?

পাঠ ০৪-এ আমরা লিখেছিলাম:
```c
printf("%d\n", 6+7);
```
এটা কাজ করে ঠিকই, কিন্তু `6` এবং `7` সংখ্যাগুলো **হার্ডকোডেড** — মানে সরাসরি কোডের ভেতরে ফিক্সড করে বসানো। যদি তোমার একই সংখ্যাগুলো দশটি ভিন্ন হিসাবে বারবার ব্যবহার করতে হয় এবং পরে একটি মান পরিবর্তন করতে হয়, তাহলে তোমাকে প্রতিটি লাইন খুঁজে বের করে এডিট করতে হবে — এতে ভুল হওয়ার এবং **ডেটা ডুপ্লিকেট** হওয়ার ঝুঁকি থাকে।

ভেরিয়েবল এই সমস্যার সমাধান করে:
- একটি মান **একবার** ভেরিয়েবলে সংরক্ষণ করো।
- প্রোগ্রামের যেকোনো জায়গায় সেই ভেরিয়েবল **পুনরায় ব্যবহার (reuse)** করো।
- মান পরিবর্তন করতে হলে, তুমি শুধু **একটি জায়গায়** আপডেট করবে, আর সেই ভেরিয়েবল ব্যবহার করা প্রোগ্রামের প্রতিটি অংশ স্বয়ংক্রিয়ভাবে নতুন মান ব্যবহার করবে।

এটা অনেকটা স্প্রেডশিটে বারবার একই কাঁচা সংখ্যা টাইপ না করে ফর্মুলা ব্যবহার করার মতো — একবার ইনপুট পরিবর্তন করলেই তার নিচের সবকিছু আপডেট হয়ে যায়।

## কোড উদাহরণ: ভেরিয়েবল দিয়ে গাণিতিক হিসাব

```c
#include <stdio.h>

int main(){
    //int n = 20;
    
    //printf("n + 5 = %d\n", n + 5);
    //printf("n - 5 = %d\n", n - 5);
    //printf("n * 5 = %d\n", n * 5);
    //printf("n / 5 = %d\n", n / 5);
    //printf("n = %d\n", n);
    
    int a = 10;
    int b = 20;
    
    printf("%d + %d = %d\n", a, b, a + b);
    printf("%d - %d = %d\n", a, b, a - b);
    printf("%d * %d = %d\n", a, b, a * b);
    printf("%d / %d = %d\n", a, b, a / b);
    
    return 0;
}
```

### ভেঙে দেখা যাক

**কমেন্ট করা অংশ:**
```c
//int n = 20;
//printf("n + 5 = %d\n", n + 5);
```
`//` দিয়ে শুরু হওয়া লাইনগুলো হলো **কমেন্ট (comments)** — কম্পাইলার এগুলো সম্পূর্ণ উপেক্ষা করে। এটা দেখতে মনে হচ্ছে প্রোগ্রামের আগের একটি ভার্সন (যেখানে একটি মাত্র ভেরিয়েবল `n` একটি ফিক্সড সংখ্যা `5`-এর সাথে ব্যবহার করা হয়েছিল), যা লেখক দুটি ভেরিয়েবল দিয়ে পুনরায় লেখার সময় রেফারেন্স/স্মারক হিসেবে রেখে দিয়েছেন। এভাবে কমেন্ট রাখা একটি সাধারণ ও উপকারী অভ্যাস — এতে তুমি কোড না মুছেই আগের অ্যাপ্রোচ চোখে দেখতে পারো।

**সক্রিয় (active) কোড:**
```c
int a = 10;
int b = 20;
```
দুটি ইন্টিজার ভেরিয়েবল ডিক্লেয়ার করা হয়েছে: `a`-তে আছে `10`, আর `b`-তে আছে `20`।

```c
printf("%d + %d = %d\n", a, b, a + b);
```
এই লাইনে একই `printf` কলে **তিনটি `%d` প্লেসহোল্ডার** ব্যবহার করা হয়েছে, যেগুলো ফরম্যাট স্ট্রিং-এর পরে দেওয়া মানগুলো দিয়ে ক্রমানুসারে পূরণ হয়:
1. প্রথম `%d` → `a` → `10`
2. দ্বিতীয় `%d` → `b` → `20`
3. তৃতীয় `%d` → `a + b` → `30`

তাই এটি প্রিন্ট করবে:
```
10 + 20 = 30
```

একই প্যাটার্ন বিয়োগ, গুণ ও ভাগের ক্ষেত্রেও পুনরাবৃত্তি হয়:
```
10 - 20 = -10
10 * 20 = 200
10 / 20 = 0
```

### কিন্তু `10 / 20` কেন `0` প্রিন্ট করে?

এটা পাঠ ০৪-এ শেখা **ইন্টিজার ডিভিশন**-এর সাথে সম্পর্কিত। যেহেতু `a` ও `b` দুটোই `int`, তাই সি এখানে ইন্টিজার ডিভিশন করে:
- গাণিতিকভাবে, `10 / 20 = 0.5`
- কিন্তু দশমিক অংশ বাদ পড়ে যায়, ফলে থাকে শুধু `0`

এটা মনে রাখা জরুরি — সি শেখার শুরুতে এটা বিভ্রান্তির (এবং বাগের!) সবচেয়ে সাধারণ একটি উৎস।

## মূল শিক্ষণীয় বিষয়

- একটি **ভেরিয়েবল** হলো মেমোরিতে নাম-দেওয়া একটি স্টোরেজ জায়গা, যেখানে একটি মান রাখা হয় যা তোমার প্রোগ্রাম ব্যবহার ও পরিবর্তন করতে পারে।
- কম্পিউটার সব ডেটা **বাইনারি** আকারে সংরক্ষণ করে, প্রোগ্রাম চলাকালীন কাজের মেমোরি হিসেবে **RAM** ব্যবহার করে।
- সি একটি **স্ট্যাটিক্যালি টাইপড** ভাষা — প্রতিটি ভেরিয়েবলের একটি ডিক্লেয়ার্ড ডেটা টাইপ (`int`, `float`, `char` ইত্যাদি) থাকতে হবে, যা পরিবর্তন হয় না।
- ভেরিয়েবল ডিক্লেয়ারেশনের সিনট্যাক্স: `data_type variable_name = value;`
- সরাসরি সংখ্যা বসানোর বদলে ভেরিয়েবল ব্যবহার করলে **ডেটা ডুপ্লিকেশন** এড়ানো যায় এবং প্রোগ্রাম মেইনটেইন করা সহজ হয়।
- একটি `printf`-এ একাধিক **`%d` প্লেসহোল্ডার** ব্যবহার করা যায়, যেগুলো কমা দিয়ে আলাদা করা মানগুলো দিয়ে ক্রমানুসারে পূরণ হয়।
- দুটি `int` ভেরিয়েবল ভাগ করলেও **ইন্টিজার ডিভিশন** ঘটে — `10 / 20` এর ফলাফল `0` হবে, `0.5` নয়।

## সাধারণ ভুলগুলো

- ডেটা টাইপ ডিক্লেয়ার করতে ভুলে যাওয়া (সি এটা বাধ্যতামূলক করে — প্রথমবার শুধু `age = 20;` লিখলে হবে না, সামনে `int` লিখতেই হবে)।
- `printf`-এ `%d` প্লেসহোল্ডারের সংখ্যা আর দেওয়া মানের সংখ্যার মধ্যে গরমিল করা।
- `int / int`-এর ফলাফল দশমিক আশা করা।
- ডিক্লেয়ার করার আগেই একটি ভেরিয়েবল ব্যবহার করা — সি উপর থেকে নিচে কোড পড়ে, তাই ব্যবহারের আগেই ভেরিয়েবল ডিক্লেয়ার করতে হয়।

## অনুশীলনী

1. দুটি নতুন ইন্টিজার ভেরিয়েবল ডিক্লেয়ার করো, `x = 15` এবং `y = 4`।
2. উপরের তিন-`%d`-প্লেসহোল্ডার স্টাইল ব্যবহার করে `x + y`, `x - y`, `x * y`, এবং `x / y`-এর ফলাফল প্রিন্ট করো।
3. প্রোগ্রাম চালানোর আগেই অনুমান করো `x / y` কী প্রিন্ট করবে — তারপর চালিয়ে দেখো তোমার অনুমান ঠিক ছিল কিনা।
