# Lesson 01: Introduction to C Programming

## What is C?

C is a general-purpose, procedural programming language created in the early 1970s. It's known for being **fast, efficient, and close to the hardware**, which is why it's still one of the most influential languages in computing today — decades after it was created.

## A Bit of History

C was developed alongside the **Unix operating system**. In fact, much of Unix itself was rewritten in C, which was a huge deal at the time — most operating systems before that were written in **assembly language**, which is extremely tedious and hardware-specific.

You can think of assembly as C's "parent" in terms of the problem it solved: C gave programmers most of the control that assembly offers, but with much more readable, portable syntax. This combination is why C became the go-to language for building operating systems and system-level software.

## Why C is Called "Extensible"

C is considered an **extensible language** because:
- It has a small core set of keywords and features.
- Most of its power comes from **libraries** (like the Standard Library), which you can extend or add to.
- You can build your own functions and reusable code, extending what the language can do.

This minimal-core, library-driven design is part of why C has stayed relevant for over 50 years.

## Where is C Used Today?

C shows up almost everywhere, often invisibly, powering the systems other software runs on:

| Category | Examples |
|---|---|
| Operating Systems | Android, Windows, and parts of Apple's OS (macOS/iOS) are built with C or C-derived code |
| Embedded Systems | Microcontrollers (the tiny chips inside appliances, cars, and IoT devices) |
| Scientific Computing | High-performance systems used for simulations and research |
| Developer Tools | Text editors, compilers/interpreters for other languages |
| Networking | Network drivers and low-level networking software |
| Databases | Core engines of many database systems |
| Web | Parts of web browsers are written in C/C++ for performance |
| System Utilities | Many command-line tools and OS utilities |

## Key Takeaways

- C was born alongside Unix and shaped how operating systems are built.
- It sits close to assembly language in terms of hardware control, but is far more readable and portable.
- Its "extensible" design means the core language is small, but it's built to be extended through libraries and custom code.
- C is the foundation for operating systems, embedded devices, browsers, databases, and countless developer tools — making it one of the most important languages to learn as a beginner.
