# পাঠ ০৯: মিনি প্রজেক্ট — সিম্পল ক্যালকুলেটর

## সংক্ষিপ্ত বিবরণ

এই পাঠে আমরা এতদিন শেখা সবকিছু — ভেরিয়েবল, `scanf` দিয়ে ইনপুট নেওয়া, আর গাণিতিক অপারেটর — একসাথে ব্যবহার করে একটা ছোট্ট **ক্যালকুলেটর প্রোগ্রাম** বানাব। সাথে শিখব একটা নতুন জিনিস: `printf`-এ দশমিকের সংখ্যা নিয়ন্ত্রণ করা।

## প্রোগ্রামটি

```c
#include <stdio.h> 
//simple calculator project

int main(){
    float num1, num2, result;
    
    printf("Please enter two numbers (9 20): ");
    
    scanf("%f %f", &num1, &num2);
    
    result = num1 + num2;
    printf("%.1f + %.1f = %.1f\n", num1, num2, result);
    
    result = num1 - num2;
    printf("%.1f - %.1f = %.1f\n", num1, num2, result);
    
    result = num1 * num2;
    printf("%.1f * %.1f = %.1f\n", num1, num2, result);
    
    result = num1 / num2;
    printf("%.1f / %.1f = %.1f\n", num1, num2, result);
    
    return 0;
}
```

## এতদিনের শেখা জিনিসগুলো এক জায়গায়

এই প্রোগ্রামটা আসলে নতুন কিছু বড় কনসেপ্ট শেখাচ্ছে না — বরং দেখাচ্ছে কীভাবে আলাদা আলাদা পাঠে শেখা টুকরোগুলো একসাথে জুড়ে একটা **বাস্তব, কাজ করা প্রোগ্রাম** বানানো যায়:

| অংশ | কোন পাঠে শেখা হয়েছে |
|---|---|
| `float num1, num2, result;` | পাঠ ০৫ ও ০৬ — ভেরিয়েবল ও ডেটা টাইপ |
| `scanf("%f %f", &num1, &num2);` | পাঠ ০৮ — `&` দিয়ে একসাথে একাধিক ইনপুট নেওয়া |
| `result = num1 + num2;` | পাঠ ০৪ ও ০৫ — গাণিতিক অপারেটর |
| `printf(...)` | পাঠ ০৩ ও ০৬ — আউটপুট ও ফরম্যাট স্পেসিফায়ার |

এটাই প্রোগ্রামিং শেখার আসল প্যাটার্ন — ছোট ছোট কনসেপ্ট আলাদাভাবে শেখো, তারপর সেগুলো একসাথে জুড়ে একটা কার্যকর প্রোগ্রাম বানাও।

## কোড ব্যাখ্যা

```c
//simple calculator project
```
এটি একটি **কমেন্ট**, যেটা পুরো ফাইলের একদম উপরে লেখা — এটা প্রোগ্রামের উদ্দেশ্য বোঝাতে সাহায্য করে। বড় প্রোগ্রামে ফাইলের শুরুতে এমন একটা ছোট বর্ণনা লেখা ভালো অভ্যাস।

```c
float num1, num2, result;
```
তিনটি `float` ভেরিয়েবল একসাথে ডিক্লেয়ার করা হয়েছে — দুটো ইনপুট সংখ্যার জন্য (`num1`, `num2`), আর একটা হিসাবের ফলাফল রাখার জন্য (`result`)।

```c
scanf("%f %f", &num1, &num2);
```
একটি লাইনেই দুটো সংখ্যা নেওয়া হচ্ছে। ইউজার `printf`-এর নির্দেশ অনুযায়ী স্পেস দিয়ে আলাদা করে দুটো সংখ্যা লিখবে, যেমন: `9 20`।

```c
result = num1 + num2;
printf("%.1f + %.1f = %.1f\n", num1, num2, result);
```
প্রথমে যোগফল হিসাব করে `result`-এ রাখা হচ্ছে, তারপর সেটা প্রিন্ট করা হচ্ছে। একই প্যাটার্ন বিয়োগ, গুণ, আর ভাগের জন্যও পুনরাবৃত্তি হয়েছে — প্রতিবার `result`-এর আগের মান নতুন হিসাব দিয়ে ওভাররাইট (নতুন করে বসানো) হয়ে যাচ্ছে।

## নতুন জিনিস: `%.1f` — দশমিকের সংখ্যা নিয়ন্ত্রণ

এতদিন আমরা `%f` ব্যবহার করেছি, যেটা ডিফল্টভাবে ৬ ঘর দশমিক পর্যন্ত প্রিন্ট করে (যেমন `45.450001`)। কিন্তু এখানে ব্যবহার হয়েছে **`%.1f`**।

- `.1` অংশটা বলে দেয় কম্পাইলারকে: "দশমিকের পরে শুধু **১ ঘর** দেখাও।"
- তাই `9.0` এবং `20.0` যোগ করলে `%.1f` প্রিন্ট করবে `29.0`, `29.000000` নয়।

### আরও উদাহরণ

| ফরম্যাট স্পেসিফায়ার | দশমিকের ঘর | `3.14159`-এর আউটপুট |
|---|---|---|
| `%f` | ৬ (ডিফল্ট) | `3.141590` |
| `%.1f` | ১ | `3.1` |
| `%.2f` | ২ | `3.14` |
| `%.3f` | ৩ | `3.142` (রাউন্ড হয়ে যায়) |

**গুরুত্বপূর্ণ:** `%.3f`-এ দেখো `3.14159` কে রাউন্ড করে `3.142` বানানো হয়েছে (`3.141` নয়) — কারণ চতুর্থ দশমিক ঘরে থাকা `5` উপরের ঘরকে এক বাড়িয়ে দিয়েছে। এটা সাধারণ গোল/রাউন্ডিং নিয়মের মতোই কাজ করে, শুধু কেটে ফেলে না (truncate করে না)।

## যদি ইউজার `20` এর জায়গায় `0` দেয়?

```c
result = num1 / num2;
```

যদি ইউজার `num2`-এর মান `0` দিয়ে দেয়, তাহলে `num1 / num2` হয়ে যাবে একটি সংখ্যাকে শূন্য দিয়ে ভাগ করার চেষ্টা — এটাকে বলে **division by zero**।

- `float`-এর ক্ষেত্রে (`int`-এর মতো নয়), এর ফলাফল সাধারণত `inf` (ইনফিনিটি) বা `nan` (Not a Number) হিসেবে প্রিন্ট হয়, প্রোগ্রাম ক্র্যাশ করে না।
- তবুও এটা একটা ভালো প্রোগ্রামিং অভ্যাস না — বাস্তব প্রোগ্রামে ভাগ করার আগে চেক করে নেওয়া উচিত `num2` শূন্য কিনা। এই ধরনের চেকিং শেখা হবে `if` কন্ডিশনের পাঠে।

## মূল শিক্ষণীয় বিষয়

- ছোট ছোট আলাদা কনসেপ্ট (ভেরিয়েবল, ইনপুট, অপারেটর, আউটপুট) একসাথে জুড়ে একটা কার্যকর প্রোগ্রাম বানানো যায়।
- `%.1f`, `%.2f` ইত্যাদি দিয়ে `printf`-এ দশমিকের সংখ্যা নিয়ন্ত্রণ করা যায় — সংখ্যাটা প্রয়োজনে রাউন্ডও হয়।
- একই `result` ভেরিয়েবল বারবার নতুন হিসাব দিয়ে পুনরায় ব্যবহার (reuse) করা যায় — প্রতিবার নতুন ভেরিয়েবল বানানোর দরকার নেই।
- শূন্য দিয়ে ভাগ করলে (division by zero) `float`-এর ক্ষেত্রে প্রোগ্রাম ক্র্যাশ না করলেও, `inf` বা `nan`-এর মতো অস্বাভাবিক ফলাফল আসতে পারে।

## সাধারণ ভুলগুলো

- `%.1f`-এর বদলে ভুলে `%1.f` বা `%f.1` লিখে ফেলা — সঠিক ক্রম হলো `%` তারপর `.সংখ্যা` তারপর `f`।
- `result`-কে নতুন হিসাব দিয়ে আপডেট না করেই আগের মান প্রিন্ট করা।
- ইনপুট হিসেবে দ্বিতীয় সংখ্যায় `0` দিলে কী হবে তা না ভেবেই ভাগ করা।

## অনুশীলনী

1. প্রোগ্রামটাতে আরেকটা হিসাব যোগ করো — **মডুলাস** (`%`)। (মনে রাখো, `%` অপারেটর `float`-এর সাথে সরাসরি কাজ করে না, শুধু `int`-এর সাথে কাজ করে — তাই এটার জন্য তোমাকে ভাবতে হবে কীভাবে সমাধান করবে, অথবা `int` দিয়ে আলাদা একটা উদাহরণ বানাতে পারো।)
2. `%.1f`-এর বদলে `%.3f` ব্যবহার করে প্রোগ্রামটা চালাও, এবং দেখো আউটপুট কীভাবে বদলায়।
3. প্রোগ্রাম চালিয়ে ইচ্ছাকৃতভাবে দ্বিতীয় সংখ্যা হিসেবে `0` দিয়ে দেখো ভাগ করার ফলাফলে কী প্রিন্ট হয়।
